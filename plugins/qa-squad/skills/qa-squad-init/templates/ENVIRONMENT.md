# Environment — what an agent can't deduce from the code

This file belongs to **this** project. The planner, the testers and the triage
read it before touching anything, and it exists to cut the most expensive
spend of all: an agent probing made-up addresses, assembling something that
was already up, or chasing what isn't there.

When something here stops being true, fix it. An outdated map does more harm
than no map.
