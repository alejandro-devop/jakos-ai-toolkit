# Findings register

Everything the QA squad found and stands behind. One row per finding; the
detail lives in the session file it came from.

The rules for kinds, severity and states are in [PROTOCOL.md](PROTOCOL.md);
this project's addresses and gotchas, in [ENVIRONMENT.md](ENVIRONMENT.md).

**Nothing here is fixed by this squad.** A bug leaves by dispatch, to a chain
that fixes it; an improvement waits for somebody to decide; a question waits
for somebody to answer.
