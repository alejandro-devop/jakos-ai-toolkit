# Environment — what an agent can't deduce from the code

This file belongs to **this** project. Agents read it before touching the
browser, and it exists to cut the most expensive spend of all: an agent trying
made-up addresses, mounting an environment that was already up, or chasing one
that isn't there.

If the bugs chain also runs in this repository, the same map may live at
`docs/bugs/ENVIRONMENT.md`. **There must be only one.** If both exist, delete
this one and keep the other: two maps drift apart, and the wrong one will send
someone to a place that doesn't exist.

When something here stops being true, fix it. A stale map does more damage
than no map at all.
